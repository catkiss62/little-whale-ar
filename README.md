# 小鲸鱼 AR

独立 Android 测试应用，包名 `dev.littlewhale.ar`。0.7.0 为 Redmi K80 Ultra 的桌面角色测试版，支持 arm64、Android 10 及以上。首次启动需要相机权限。

## 小鲸鱼 V21

在「选择角色」里点「作者原址下载」，或选「本机导入」并选择[作者发布的完整 V21 VRM](https://github.com/CF-612/SmallBlueFish-Model/releases/tag/dot-test-20261104-v21-fullmodel)。首次约 333 MiB，SHA-256 校验后保存在应用私有目录，再次打开可离线使用。选择「对照方块」可在同一锚点比较。

对准有纹理的桌面并平移，提示手机已定位后点「放置小鲸鱼」。绕到背面，点尾鳍的可见部分，看头、颈和身体转向镜头。首次调试请关注脚底是否贴桌、移开镜头后的恢复位置和定位 FPS。渲染和定位分开运行，定位 FPS 不能代表角色实际渲染帧率。

本版使用 WebView WebGL2、Three.js 和 glTF 蒙皮与自然垂臂站姿，不含 Unity 或完整 UniVRM 表情、布料与毛发物理。角色保留 V21 原始骨骼，移动版按需读文件片段、按绑定保留眨眼、放松和四向视线，跳过其余表情增量及完全透明的表情网格，材质使用原底色和贴图，最长边限制为 1024 像素。

模型来源 CF-612 / SmallBlueFish-Model，形象参考「这个刀子真甜」，原形象 @ZipZipPipe、@上善无形。作者的 V21 文件要求署名，仅个人非商用试验，禁止再分发。APK 内只有渲染程序，模型从作者源首次取得。

## 方块真机试法

1. 找一张光线均匀的桌子，放一本封面有图案的书。让桌面占据大部分画面。
2. 手持手机缓慢左右**平移**，直到出现「手机已定位」。点击「放置方块」。引擎从可见特征点拟合平面，在该平面上放置方块。
3. 记住方块底边相对于书角的位置。向侧面、背面绕行，再回到起点。记录底边是否滑走、是否看到不同颜色的面，以及底栏的定位 FPS。FPS 来自已完成的定位结果回调。
4. 短暂遮住镜头，再对准原来的桌面，观察方块能否回到原处。点击「重新扫描」可换一张桌子。从后台回来后重新扫描放置。

单目地图没有绝对厘米刻度。初次放置时根据相机距离确定方块大小，之后保持该地图尺度。纯色、反光或暗光桌面容易缺少定位特征。

## 从源码构建

使用 JDK 17、Node.js 22 和 Android SDK。执行：

```sh
bash scripts/prepare.sh
(cd viewer && npm ci && npm run build)
bash upstream/gradlew :app:assembleRelease
```

待签名 APK 位于 `app/build/outputs/apk/release/app-release-unsigned.apk`。准备脚本按提交号取依赖和 OpenCV 子模块。相机采集、定位服务和桌面拟合复用 [MenthaAR](https://github.com/Olsc/Android_ORB-SLAM2s/tree/913d2c13ec300e9aaa148a45de2b14a5de805f63)。测试应用从 SDK 读取同帧的模型、视图、投影矩阵，并按相机预览的旋转和尺寸绘制方块。首轮无需安装 ARCore 或 Unity。

项目记录与角色交互的后续入口见 [PROJECT_LEDGER.md](PROJECT_LEDGER.md)。引擎、相机和 SDK 原始许可见[上游许可索引](https://github.com/Olsc/Android_ORB-SLAM2s/blob/913d2c13ec300e9aaa148a45de2b14a5de805f63/LICENSE)。

### 0.3.0 角色与更新

取得完整 V21 后，可在角色菜单选择「导出原始 VRM」，将原文件保存至自己的下载目录。另一安装可从「本机导入」读取这份文件。原作者与署名见上文。

角色菜单可选 30 或 60 FPS 上限。状态行分别显示定位结果与角色绘制频率。放置后可点额头、在头部内来回抚摸、绕到背后点尾巴。

从 0.3.0 起，测试交付包使用固定 AR 签名。CI 的 unsigned-candidate 只供签名使用。发布时运行 `bash scripts/sign-apk.sh unsigned.apk output.apk`，私有环境提供 AR_KEYSTORE 和 AR_PASSWORD_FILE，脚本会核对公开证书指纹。0.1.0 与 0.2.0 的旧临时签名无法覆盖迁移。


### 0.4.0 待机和摸头

小鲸鱼放下双臂站立，偶尔看向镜头。在侧后方停留约两秒，她会慢慢转过来；经过或抚摸时不会触发这次自动转身。点尾巴仍可主动让她回头。

轻点头部会点头。在头发上连续划动时，她会持续闭眼、歪头，底栏会显示「正在摸头」。松开后恢复待机。桌面提示分别说明手机定位、尝试寻找桌面、放置超时这几个阶段。

### 0.5.0 模型大小与活动范围

角色菜单可设 25%～200% 七档大小，默认 100%，下次启动沿用。缩放中心在脚下。小鲸鱼偶尔注意镜头时，颈部和头部会随相机高度、左右角度调整。

放置小鲸鱼后，打开角色菜单的「绘制活动范围」，从上方沿桌面划出一个包含她脚下的轮廓，松手自动闭合。她会在范围内转向、迈步、停留。支持简单凹形，边线相交会提示重画。重新打开该入口可以改画、取消或清除。重新扫描和结束会话会清除活动区；模型大小会保留。

相机逐步跟踪并建立地图；放置时记录地图编号和桌面锚点。失跟、进入另一张地图后会隐藏角色，原地图恢复并取得连续三个有效结果后再显示。活动范围和当前位置保存在该次放置的桌面坐标中。首版根据手画边界约束脚下路径，桌沿、杯子等真实障碍应由使用者画在范围外。

### 0.5.1 持续看镜头

镜头停在她面前时，小鲸鱼会一直朝镜头看。抬高、放低或左右移动手机，她的头和眼睛会平滑跟随。摸头时她随手指反应，松开后重新看向镜头。

### 0.6.0 掌上模式

在角色菜单选择「掌上模式」，后置镜头对准张开的掌心。稳定识别后小鲸鱼出现，随掌心移动和远近调整大小；短时遮挡停留，持续丢手则隐藏。返回桌面后重新扫描放置。掌上识别在本机运行，使用随 APK 内置的 Google MediaPipe Hand Landmarker，角色沿用已导入的 V21。转身时头部的左右偏转随肩膀转动减小，抬头仍跟随镜头。

### 0.6.1 掌面点选与摸头

摊手后，点浅绿色轮廓内想让她站的位置。脚下的点随掌面移动和转动，丢手后同侧手再次入镜时沿用选点。角色菜单可重新选择掌上站位。摸头时从现有注视角度低头、歪头，转身结束时头部稍晚收正。

### 0.6.2 掌面立体视角

放置后保持手掌摊开，从斜上方向左右移动手机，可观察身体侧面和头顶。身体朝向随手掌保持，点尾巴仍可主动转身。默认鞋底对准点选位置。需要补偿时，在角色菜单的「掌上站位微调」选择上移四分之一身或半身。

### 0.7.0 桌面提起与掌上转身

桌面放置后可长按身体约半秒提起，再拖动或移动手机。先绘制活动范围，脚下出现绿圈时松手可放到新位置，范围外或跟踪中断会回原位。掌上默认上移半身，也可选择鞋底对准选点。镜头在掌面侧后方停稳约两秒后，她会回头转向镜头。
